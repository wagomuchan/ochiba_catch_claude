# ochiba_catch_claude

▶ **遊ぶ: https://wagomuchan.github.io/ochiba_catch_claude/**

ひらひら落ちてくる落ち葉をタップしてキャッチするブラウザゲーム。
当たり判定は葉っぱの形そのままなので、もみじの切れ込みや虫食いの穴をタップするとすり抜ける。

## 遊び方

`index.html` をブラウザで開く（ローカルなら `python3 -m http.server` などで配信して開く）。
スマホはタップ、PCはクリック。右上の ⚙ で枚数・風・スローなどを変えられる。

## しくみ

- 落ち方: 葉っぱを「薄い板」として、抗力・揚力・圧力中心のずれ・付加質量・回転の空気抵抗を毎フレーム計算（Three.js、外部の物理エンジンなし）
- 風: 場所と時間でゆらぐ風＋ときどき通り抜ける突風
- 見た目: 葉っぱのテクスチャはその場で描いてる。逆光で透けるシェーダー付き
- `lib/` に Three.js r170 を同梱（MIT, `lib/three.LICENSE`）
